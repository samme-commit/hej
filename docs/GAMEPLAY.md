# The Forgotten Road - Gameplay Document


# Core Gameplay Loop


Explore

↓

Discover Memories

↓

Make Choices

↓

Change The World

↓

Uncover The Truth



---

# Player Identity


The player does not choose a traditional class.

Instead, their identity is created through actions.


The game remembers:

- Choices
- Discoveries
- Items
- Memories
- Relationships


---

# Progression System


Progression is based on discovery.

The player grows by:

- Finding memories
- Learning forgotten abilities
- Recovering items
- Exploring new areas


---

# Stats


## Health

Represents physical survival.


## Strength

Determines combat power.


## Knowledge

Determines interaction with memories and mysteries.


## Awareness

Determines exploration abilities.


---

# Memory System


Memories are the main progression system.


A memory can:

- Unlock dialogue
- Reveal lore
- Change locations
- Unlock abilities


Example:


Memory:

"The Last Battle"


Effect:

Unlocks knowledge about the Broken Sword.


---

# Combat


Combat is simple but meaningful.


Possible actions:

- Attack
- Defend
- Use Item
- Use Memory Ability


Combat should focus on choices, not speed.


---

# Choices


Choices are permanent.

The player should not always know the consequence.


Example:


Choice:

Take the sword.


Possible consequence:

Gain power.

Lose another opportunity.


---

# Exploration


Exploration reveals:

- Locations
- Memories
- Hidden paths
- Lore


The world should reward curiosity.


---

# Items


Items have history.

An item is not just a stat upgrade.


Example:


Broken Sword

Attack: +10

Memory:

"The blade remembers a battlefield."


---

# Endgame


The player's final decision determines the fate of the world.


The player chooses:

- Restore memory
- Preserve forgetting
- Become the Keeper
