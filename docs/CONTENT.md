# The Forgotten Road - Content Document


# Game Structure

The game is divided into chapters.

Each chapter reveals more about:

- The world
- The player's identity
- The Great Forgetting
- The Hollow


The player should always have unanswered questions.


---

# Chapter 1 - The Awakening


## Purpose

Introduce:

- The player
- The first choice
- The memory system
- The mystery of the world


---

# Location: The Forgotten Road


## Description

A forgotten road covered in fog.

The player awakens with no memory.

Nearby:

- A broken sword
- A strange stone
- A path disappearing into the mist


---

# First Choice


## The Broken Sword


### Gameplay

Starting weapon.

Unlocks combat path.


### Memory

"The Last Battle"


### Future Connections

The player discovers their connection to an ancient conflict.


---

## The Forgotten Stone


### Gameplay

Unlocks memory abilities.

Increases survivability.


### Memory

"The Voice In The Dark"


### Future Connections

Reveals information about The Great Forgetting.


---

## The Silent Road


### Gameplay

Unlocks exploration abilities.

Reveals additional locations.


### Memory

"The Place That Should Not Exist"


### Future Connections

Shows that the world is not as stable as it appears.


---

# Chapter 1 Events


## The First Enemy

Name:

The Forgotten Guard


Description:

A warrior who has protected a place that no longer exists.


Purpose:

Tutorial combat.


Reward:

First real memory fragment.


---

## First NPC

Name:

Unknown Wanderer


Description:

A traveler who remembers pieces of the old world.


Purpose:

Introduce the idea that memories can be unreliable.


Possible Dialogue:

"You look like someone I once knew."

## Restore Memory

The world remembers.


Consequence:

Humanity faces the truth.


---

The world remains peaceful.


Consequence:

The truth disappears forever.


---

## Become The Keeper

The player protects memory.


Consequence:

The cycle continues.


---

# Content Rules


Every piece of content should answer at least one question:


- Does this reveal something about the world?
- Does this reveal something about the player?
- Does this create an interesting choice?


Avoid content that exists only for decoration.
